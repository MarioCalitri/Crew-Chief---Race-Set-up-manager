# Crew Chief 🏎️🏁

**Crew Chief** is a purpose-built mobile and web application designed for grassroots short-track and oval racing teams. It eliminates greasy paper pit notebooks, fragmented setup sheets, and scattered tire logs by consolidating chassis measurements, session telemetry, tire management, live timing, and printable post-race reports into a single digital dashboard.

---

## 🔑 Key Features

* **Setup & Chassis Tracking:** Log alignment stats, spring rates, ride heights, stagger, and weight scaling across different track conditions and events.
* **Tire Management System:** Track tire sets, cold/hot pressures, pyrometer temperatures, roll-outs, and wear across practice, heat races, and main events.
* **Live Session & Race Telemetry:** Keep real-time records of driver feedback, gearing adjustments, lap times, and handling changes during track sessions.
* **Printable PDF Race Summaries:** Generate and export comprehensive, publication-ready PDF summaries of complete race events—combining chassis setups, weather logs, tire data, and session results into a single printable document for physical binders or sponsor updates.
* **Data Visualizations & Analytics:** Compare setup changes against track performance over time to establish repeatable winning baselines.

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** JavaScript / Web Components, HTML5, CSS3
* **PDF Generation:** jsPDF / pdfmake (Client-side dynamic document rendering)
* **Backend / API:** RESTful API integrations (Live Timing & Custom Racing Data Services)
* **Design & Prototyping:** Figma, Adobe Illustrator, Adobe Photoshop
* **Dev Environment:** Linux / Fedora Workstation (UTM Virtual Machine on macOS)
